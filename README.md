# Lakshapathi - Who wants to be a Millionaire Quiz Game  
A desktop based quiz game inspired by " Who wants to be a Millionaire" built with C# Windows Forms. This is my HNDIT First Year group project.
### Features
-Interactive UI with 4+ windows forms 
-Multiple choice questions (A,B,C,D)
-Dynamic score & Price Money System
50-50 Audience poll, & Phone a Friend Lifelines
Engaging sound effect and images

### Tech Stack
-Language:C#,
-Framework:.NET Framework
-UI: Windows Forms (WinForms)
-IDE: Visual Studio 2022

### How to Run
1. Clone this repository :`git clone https://github.com/hirundiherath574-hub/Lakshapathi-Quiz-Game.git`
2. open the `ලක්ෂපති.sln` file in visual studio
3. Press `F5` or click start to run
